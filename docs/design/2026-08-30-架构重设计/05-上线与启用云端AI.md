## 顾问/客户上线时：如何开启云端 AI

1. 决定凭据模式（D11）：
   - 订阅：`WB_CLOUD_AI_AUTH=subscription`（默认），worker 用登录态 `claude -p`。
   - API Key：`WB_CLOUD_AI_AUTH=apikey`，worker 从 api-vault 取 `ANTHROPIC_API_KEY`。
     **无人值守给多个顾问/客户跑，建议 apikey**（不受个人额度波动、不混上下文）。
   - 注意：`code-exec`(resident-worker 的 codex)用 Codex 自有鉴权，不受此开关影响。
2. 给相关服务设 `WB_CLOUD_AI=on`（在 systemd drop-in 或 env 文件里），需要 apikey 时再设 `WB_CLOUD_AI_AUTH=apikey`。
3. 启用并启动 worker：`sudo systemctl enable --now resident-worker`。
4. 验证：control-tower 显示已启用；`/api/inbox/*` 不再 503；提交一条测试反馈看 worker 是否认领处理。
